Task Manager
A simple Task Manager application built using Next.js, react, tailwind.css. This project allows users to manage their daily tasks with a clean and responsive interface.

Features:
-  Add new tasks
-  Edit existing tasks
-  Mark tasks as completed
-  Delete tasks
-  Responsive UI built with Tailwind CSS

 Technologies Used :
- Next.js
- React
- Tailwind CSS
- JavaScript
- Git & GitHub
